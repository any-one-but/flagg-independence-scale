# Flagg Independence Scale

A lightweight, web-based diagnostic tool for assessing functional independence across five core life domains.

## Domains

| Row | Domain |
|-----|--------|
| 1 | Shelter |
| 2 | Transportation |
| 3 | Water and Food |
| 4 | Safety and Security |
| 5 | Health and Wellbeing |

## How it works

Each domain has five options ranked left to right (1–5). Select one option per row. A running score out of 25 appears once any selection is made.

## Design

Single-file HTML/CSS/JS — no build step, no dependencies, no server required. Designed to be calm, flat, and accessible on both desktop and mobile.

## Development

Open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8080
```
